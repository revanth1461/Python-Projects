# 🎵 MoodMate

A beginner-friendly Python CLI application that recommends music albums based on your current mood.

## ✨ Features

* 😊 Happy mood recommendations
* 😢 Sad mood recommendations
* 😰 Stressed mood recommendations
* 🤩 Excited mood recommendations
* 🎲 Randomly selects 3 albums
* 🔗 Provides Spotify search links
* ⚠️ Handles unsupported moods
* 🧩 Uses Python functions for clean code
* 💻 Simple command-line interface

## 🛠️ Technologies Used

* Python
* Random module
* Dictionaries
* Lists
* Functions
* Conditional statements

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project

```bash
cd 01_MoodMate
```

### 3. Run the application

```bash
python main.py
```

### 4. Enter your mood

Choose one:

```text
happy
sad
stressed
excited
```

MoodMate will randomly recommend 3 albums.
